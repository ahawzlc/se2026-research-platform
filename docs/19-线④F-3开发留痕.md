# 线④ F-3：我的待办·跨项目聚合视图

基线：develop `ae7f035`（F-2 已合入，社区 E-1/E-2 已合入）。本卡不改数据库，不新增后端接口；复用已有项目、任务分页接口和项目权限过滤。

## 实现范围

- 工作台新增“我的待办”卡片，聚合当前用户在所有项目中被指派且未完成的任务。
- 任务展示标题、所属项目、截止日期；逾期任务显示红色“已逾期”。
- 筛选：全部、我逾期的、本周到期。
- 按截止日期升序；没有截止日期的任务排在末尾；同日期按标题稳定排序。
- 点击任务跳到 `/tasks?projectId=…` 对应项目看板。
- 当前用户通过已有 `/auth/me` 与 Pinia user store 获取；任务归属使用后端返回的 `assigneeId` 字符串比较。
- 项目任务超过 100 条时前端继续分页读取，避免跨项目聚合遗漏任务。

## 决策与边界

- 跨项目聚合在前端完成，沿用 `loadOverview` 已有的项目/任务并行查询；每个请求仍由后端按当前用户课题组过滤。
- 任务状态 `done` 在聚合前排除，避免已完成任务出现在待办。
- “本周到期”按浏览器本地日期的当前周一至周日计算；日期字段是后端的 `yyyy-MM-dd`，不做时区转换。
- 没有截止日期的任务可在“全部”看到，不进入“逾期”或“本周到期”。
- 无任务或筛选结果为空显示空状态；聚合失败不影响工作台其他卡片。
