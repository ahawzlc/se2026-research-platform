## 文档的效力

本目录下的文档属于**接口与数据的冻结约定**。一旦某份文档确认，任何违背它的实现都视为缺陷。需要变更时，先在群内提出，修改文档并同步给受影响的人，再动代码——**不允许"先写代码、后补文档"**。
