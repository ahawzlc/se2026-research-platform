# 接口规范

本文件为前后端共同遵守的接口约定。前端封装（`frontend/src/api/request.ts`）已按本规范实现，后端请对齐同样的返回结构，否则前端需额外适配。

## 一、基本约定

| 项 | 约定 |
| --- | --- |
| 接口前缀 | `/api/v1` |
| 风格 | RESTful，用 HTTP 方法表达动作 |
| 请求/响应体 | `application/json`，文件上传除外（`multipart/form-data`） |
| JSON 字段命名 | 小驼峰（`createdAt`、`assigneeId`） |
| URL 路径命名 | 全小写，多单词用中划线（`/literature-tags`） |
| 时间格式 | `yyyy-MM-dd HH:mm:ss`（如 `2026-10-14 16:30:00`）；仅日期用 `yyyy-MM-dd` |
| 字符集 | UTF-8 |

## 二、统一返回体

所有接口（含错误）都返回同一结构：

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int | 业务状态码，`0` 表示成功，非 0 表示失败 |
| `message` | string | 提示信息，成功时为 `ok`，失败时为可直接展示给用户的文案 |
| `data` | any | 数据体，失败时为 `null` |

### 业务状态码

| code | 含义 | 前端处理 |
| --- | --- | --- |
| `0` | 成功 | 取 `data` 使用 |
| `400` | 参数校验失败 | 提示 `message` |
| `401` | 未登录 / 令牌失效 | 清除本地令牌并跳转登录页 |
| `403` | 已登录但无权限 | 提示无权限，不做跳转 |
| `404` | 资源不存在 | 提示并返回列表页 |
| `409` | 状态冲突（如邀请码重复、重复入组） | 提示 `message` |
| `500` | 服务端异常 | 提示「服务异常，请稍后重试」 |

HTTP 状态码仍按语义返回（成功 200、未授权 401 等），但**前端以业务 `code` 为准**，不依赖 HTTP 状态码判断成败。

## 三、鉴权

- 需要登录的接口在请求头携带令牌：

```
Authorization: Bearer <token>
```

- 令牌由登录接口签发，前端持久化在 `localStorage`，由 Axios 请求拦截器自动注入；
- 令牌失效返回 `code: 401`，前端响应拦截器统一处理为「清令牌 + 跳登录」；
- **所有涉及课题组数据的查询，后端都必须附加团队标识条件**，防止越权访问他人数据。

## 四、分页

列表接口统一使用 `page` 与 `size` 两个查询参数：

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `page` | int | 1 | 页码，**从 1 开始** |
| `size` | int | 10 | 每页条数，服务端限制上限 100 |

分页响应统一结构（放在 `data` 中）：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "list": [],
    "total": 0,
    "page": 1,
    "size": 10
  }
}
```

## 五、接口清单

### 认证

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/v1/auth/register` | 注册，入参 `username`、`password`、`nickname`、`email` |
| POST | `/api/v1/auth/login` | 登录，返回 `token` 与用户信息 |
| POST | `/api/v1/auth/logout` | 登出（可选，无状态令牌下可为空实现） |
| GET | `/api/v1/auth/me` | 获取当前登录用户 |

### 课题组

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/v1/teams` | 创建课题组，返回邀请码 |
| GET | `/api/v1/teams/{id}/members` | 获取课题组成员 |
| POST | `/api/v1/teams/join` | 凭邀请码入组 |
| PUT | `/api/v1/teams/{id}/members/{userId}/role` | 修改成员角色 |

### 项目与里程碑

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST / PUT / DELETE | `/api/v1/projects`、`/api/v1/projects/{id}` | 项目增删改 |
| GET | `/api/v1/projects` | 项目列表（分页） |
| POST / PUT / DELETE | `/api/v1/milestones`、`/api/v1/milestones/{id}` | 里程碑维护 |

### 任务

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/v1/tasks` | 新建任务 |
| GET | `/api/v1/tasks` | 任务查询（按项目、状态、负责人过滤） |
| PUT | `/api/v1/tasks/{id}/status` | 任务状态流转（看板换列） |
| PUT | `/api/v1/tasks/{id}/order` | 调整看板排序 |
| GET / POST | `/api/v1/tasks/{id}/comments` | 任务下评论读取与发表 |

### 文献、会议、成果

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST / GET / PUT / DELETE | `/api/v1/literatures`、`/api/v1/literatures/{id}` | 文献维护（含标签、阅读状态） |
| POST / GET / PUT / DELETE | `/api/v1/meetings`、`/api/v1/meetings/{id}` | 会议记录维护 |
| POST / GET / DELETE | `/api/v1/achievements`、`/api/v1/achievements/{id}` | 成果登记与成员关联 |

### 协作沟通

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET / POST | `/api/v1/conversations/{id}/messages` | 会话消息拉取与发送 |
| GET | `/api/v1/conversations/unread` | 未读消息汇总（**前端轮询，3–5 秒**） |
| POST | `/api/v1/conversations/{id}/read` | 标记会话已读 |

### 统计与文件

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/v1/stats/contribution?teamId=` | 贡献度分析结果 |
| POST | `/api/v1/files/upload` | 统一文件上传，返回文件标识 |

## 六、请求与响应示例

新建任务：

```http
POST /api/v1/tasks
Authorization: Bearer eyJhbGciOiJIUzI1NiIs...
Content-Type: application/json

{
  "projectId": 12,
  "title": "完成文献综述初稿",
  "assigneeId": 5,
  "priority": "high",
  "dueDate": "2026-10-20"
}
```

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": 108,
    "projectId": 12,
    "title": "完成文献综述初稿",
    "assigneeId": 5,
    "status": "todo",
    "priority": "high",
    "dueDate": "2026-10-20",
    "createdAt": "2026-10-14 16:30:00"
  }
}
```

失败示例：

```json
{
  "code": 401,
  "message": "登录状态已失效，请重新登录",
  "data": null
}
```
